# Icon

<p class="lead">Built-in SVG icon wrapper for lightweight status and control icons.</p>

<DemoFrame demo="icon" title="Icon demo" :height="220" />

## API

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| `name` | Built-in icon name. | `string` | required |
| `size` | Icon size in px or CSS length. | `string \| number` | `16` |
| `color` | Override icon color. | `string` | `''` |
| `spin` | Enable continuous rotation. | `boolean` | `false` |
