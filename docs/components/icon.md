# Icon

<p class="lead">内置 SVG 图标组件，适合轻量状态图标和操作图标场景。</p>

<DemoFrame demo="icon" title="Icon 示例" :height="220" />

## API

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `name` | 内置图标名称。 | `string` | 必填 |
| `size` | 图标尺寸，支持数字或 CSS 长度。 | `string \| number` | `16` |
| `color` | 自定义图标颜色。 | `string` | `''` |
| `spin` | 是否启用旋转动画。 | `boolean` | `false` |
