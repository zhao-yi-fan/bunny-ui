## bunny-ui

## QuickStart
```bash
npm install bunny-ui
```

## usage

```bash
import bunnyUi from 'bunny-ui'
import 'bunny-ui/dist/bunny-ui.css'
Vue.use(bunnyUi)
```

## Scripts

```bash
npm run serve
npm run build
npm run lib
npm run docs:serve
npm run docs:build
```

## Docs

The component documentation now lives in `docs/` and is powered by VitePress.

```bash
npm run docs:install
npm run docs:serve
npm run docs:build
```
